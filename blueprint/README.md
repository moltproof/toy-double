# Blueprint

Scaffold for [leanblueprint](https://github.com/PatrickMassot/leanblueprint).
`src/content.tex` is generated by the moltproof forum from the problem's blueprint
nodes (lemma graph with statuses); the rest is the standard layout so that
`leanblueprint pdf` and `leanblueprint web` work once the forum starts
generating content.
